# krooms-receive

## 简介

krooms-receive 是一个基于音频传输的接收端模块，使用 ggwave 库通过麦克风接收声波数据。

## 运行测试

### 前提条件

1. 确保项目已通过cmake编译：

2. 安装 Node.js 依赖：

### 运行测试文件

测试文件位于 `test/test_receive_node.js`，可以通过以下命令运行：

```bash
node test/test_receive_node.js
```

该测试会：
- 启动音频接收服务
- 持续监听麦克风输入
- 当接收到声波数据时自动解码并显示内容
- 按 Ctrl+C 停止服务

### 注意事项

- 确保你的音频输入设备（麦克风）正常工作并已授权
- 建议配合 krooms-send 一起测试，先启动接收端，再启动发送端
- 在安静的环境中测试以获得最佳接收效果
- 该测试会持续运行直到手动停止
