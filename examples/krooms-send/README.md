# krooms-send

## 简介

krooms-send 是一个基于音频传输的发送端模块，使用 ggwave 库通过声波发送数据。

## 运行测试

### 前提条件

1. 确保项目已通过cmake编译：

2. 安装 Node.js 依赖：

### 运行测试文件

测试文件位于 `test/test_send_node.js`，可以通过以下命令运行：

```bash
node test/test_send_node.js
```

该测试会：
- 启动音频发送服务
- 每 5 秒自动更新发送的消息内容
- 通过声波发送数据
- 按 Ctrl+C 停止服务

### 注意事项

- 确保你的音频输出设备正常工作
- 建议在安静的环境中测试以获得最佳效果
- 该测试会持续运行直到手动停止
